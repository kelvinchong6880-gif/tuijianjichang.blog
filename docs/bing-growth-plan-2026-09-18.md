## 为什么可能有竞争力：观察与推断分开

观察：多个页面直接匹配购买选择意图，有可比较价格、品牌详情、场景选择、教程和更新信息。不同类型页面都能出现在本次结果中。

推断：这些结构有助于回答查询和减少读者再次搜索，是值得改进的方向；无法凭它们证明某页面具体为什么排第几。未取得竞争站外链、历史流量、索引历史、用户行为及 Bing 内部评分。

微软公开说明 Bing 综合考虑相关性、质量与可信度、用户互动、新鲜度、地区语言和加载时间。作者与来源、事实和意见的区分、其他站点的链接声誉均属于需要考虑的方向。参见 [How Bing delivers search results](https://support.microsoft.com/en-us/bing/how-bing-delivers-search-results) 与 [Bing Webmaster Guidelines](https://www.bing.com/webmasters/help/webmaster-guidelines-30fba23a)。这些不是对本次竞争站的因果判断，也不意味着满足清单便保证排名。

## 当前项目已确认的缺口

- 已有首页筛选、推荐页、品牌页、场景页、比较页和方法论，现有基础值得保留。
- `/recommend/` 的多个推荐理由重复为“具备竞争力的套餐配置组合”，没有用具体差异帮助选择。
- 推荐页“月付 ¥entryPrice”适合人群文案将品牌最低标价视为月付。SOGO 品牌文案却记录季付 ¥25，存在冲突。
- 套餐表组件把月付、一次性以外的周期统称“其他”，无法清楚查看季付与年付。
- SOGO 计费与流量规则需回查原始资料。当前数据库中季度字段是否代表总扣款，不能仅凭现有文案或变量名确认。
- 套餐模型没有独立流量重置周期字段；不能把年付、季付流量默认视为全周期总量或月额度。
- 首页偏数据库工具，核心词目标页暂定 `/recommend/`，应加强首页对它的显著导航。不要未经数据依据就迁移 URL 或将全站都改成相同标题。
- 当前页面列表未见独立关于、作者、联系纠错和教程页；方法论已有利益关系与测试边界说明，可扩展而非重复建空页。
- canonical 与 Astro site 指向已确认正式域名 `.blog`，当前不是需要改域名的问题。
- 本次读取线上首页失败，不能因此断言网站未上线、停运或未收录。线上可达性和 Bing 索引需单独核实。

## 分阶段完成与验收

### 第一步：计费资料与全站价格口径（下一次实施）

先记录工作区现状。定位 SOGO 原始套餐资料及其他品牌关键价格来源。逐项核对价格是月付、季付总额或其他，流量是每月重置、全周期总量或不限时总量。找不到依据就标记待核实，不改造成猜测。为数据添加可追溯来源、资料日期和流量周期字段；更新受影响的品牌表、推荐文案与价格标签。验收 SOGO 各套餐跨页面一致，其他周期不被显示为月付；¥/GB 仍清楚说明原始比值口径。

### 第二步：完成核心机场推荐页

保持 `/recommend/`。加入简明选择结论、目录、SOGO 主推及关系披露、每个候选的不同理由、明确不适合人群、周期价格对比和待验证项目。所有数量动态生成；只有实际核对日期可作为核对日期。验收每条结论能关联具体资料，禁止通用重复段落、虚构评分与实测。

### 第三步：完成 SOGO 决策页

补周期套餐和不限时如何选、不同流量需求的示例、购买前核对事项、优惠码适用条件及验证状态、兼容与导入资料、退款与客服资料。缺失项目明确未说明。保留事实缺点，不称全网最稳。若用户有真实测速材料，再按地区、运营商、时段、客户端、日期、原始记录撰写测试部分。

### 第四步：信任信息与新手内容

补真实关于及作者信息、可用纠错渠道、更新记录。按已验证的客户端资料先完成一个购买后导入教程和一个故障排查教程，再依据搜索数据扩展。不要凭空捏造身份、使用年限或联系信息。

### 第五步：全站体验与技术验收

检查桌面与手机、筛选功能、表格、出站链接、状态码、canonical、robots、Sitemap、结构化数据与加载。结构化数据与可见内容一致，不加虚构用户评分。构建成功只是其中一项。

### 第六步：上线与 Bing 基线

上线前提供可审阅版本，按用户授权处理发布。确认 Bing Webmaster Tools 所有权、Sitemap、核心页面 URL 检查和索引状态；保存展现、点击、查询、目标页及平均位置基线。提交与 IndexNow 用于发现更新，不能保证索引与排名。

### 第七步：依据真实反馈迭代

先观察 SOGO 品牌词和具体套餐问题，再观察场景词，持续争取核心词。按实际查询完善已有内容、修正失效资料，获取真实相关网站引用。不购买排名链接、不堆砌批量空页。评估使用相同地区及设备的结果样本和站长工具趋势，不能只看一次手动名次。检查节奏以有效数据积累为准，不承诺若干天进入前八。
